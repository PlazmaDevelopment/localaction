# Localizer Terminal

Son zamanlarda yeni eklenen Juro Term ile çoğu developer kendi terminalini kuruyor. Kurulması kolay olan bir diğer terminal ise Localizer terminalidir. Bu terminal çoğu komut ile birden fazla özellik barındırmakta ve çoğu  alana kurulabilmekte. Tamamen bedava ve kullanımı çok kolaydır. Terminali hemen indirin. Talimatlar şunlardır:

Gerekli Araçlar
C++ derleyici (GCC, Clang veya MSVC önerilir)

Windows Terminal veya CMD

1. Depoyu Klonla
```bash
Kopyala
Düzenle
git clone https://github.com/kullaniciadi/localizer.git
cd localizer
```
2. Derleme (Windows için)
```bash
Kopyala
Düzenle
g++ -o local local.cpp
Eğer g++ komutu tanınmıyorsa, MinGW veya benzeri bir C++ derleyicisini sistem PATH’ine ekleyin.
```
3. Çalıştırma
```bash
Kopyala
Düzenle
./local
```
Windows’ta çalıştırırken
```bash
Kopyala
Düzenle
local.exe
```
